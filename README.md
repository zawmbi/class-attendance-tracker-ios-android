# Attenza

Attenza is an iOS and Android app for tracking class attendance, built with React Native, TypeScript, Zustand, and NativeWind.

Built for college and graduate students who want quick, thorough, and customizable
self-tracking — with a gamified momentum system that makes showing up feel rewarding.

## Features

- **Quick Check-In** — mark today's classes in one tap, with celebratory XP feedback.
- **Momentum & Ranks** — every check-in earns XP and climbs academic ranks
  (Freshman → Valedictorian) with a live streak counter.
- **Trophy Case** — 12 unlockable badges for streaks, comebacks, punctuality, and more.
- **Risk & projections** — see how many classes you can safely miss before falling
  below your required attendance.
- **Customizable dashboard** — reorder widgets so the things you care about come first.

## Run

```bash
npm install
npm run start
```

## Stack

- Expo + React Native + TypeScript
- Expo Router
- Zustand
- NativeWind
- Expo Notifications + Expo Location hooks
for ios and android!
